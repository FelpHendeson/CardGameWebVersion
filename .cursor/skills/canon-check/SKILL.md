# Canon Check

## Procedimento

1. Localize `00_README.md` e confirme a hierarquia vigente.
2. Leia `01_DOCUMENTO_DO_JOGO.md` para regras afetadas.
3. Leia `02_CATALOGO_DE_CARTAS.md` se qualquer carta for afetada.
4. Leia as especificações técnicas relacionadas.
5. Compare cada comportamento planejado/implementado com as fontes.
6. Classifique achados como:
   - conforme;
   - divergência;
   - ambiguidade;
   - decisão provisória;
   - documentação técnica desatualizada.
7. Não corrija ambiguidade inventando regra.

## Saída esperada

Forneça resumo curto com arquivos/fontes consultados, divergências encontradas e decisões necessárias.
